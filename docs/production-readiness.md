# 本番利用に向けた確認事項

ローカルの1人利用を基準に改善を進めます。外部公開や複数利用者での運用は、認証と隔離を検証してから判断します。

| 項目 | 対応と残る確認 |
| --- | --- |
| 接続と状態 | VNCの再接続、全環境の状態同期、古い通知の無視、遅い閲覧者による実行の遅延を修正済み。実ブラウザで切断後の復旧も確認します |
| タスク終了と回復 | 分解失敗・例外・一時停止中の停止で、失敗状態を保存して完了を通知します。回復操作の実行、残作業の再計画、再試行上限はテスト済みです |
| 環境管理 | 所属プロジェクトの照合、中継と本体の区別、共有マウント経由のディスク削除、Docker操作の失敗通知を追加しました |
| 実環境の検査 | Firefoxの実体を導入し、描画とVNC入力後のファイル内容をCIで検査します。QEMUとAndroidの実機検査は追加が必要です |
| KVMの初回起動 | ゲストファイルの事前確認と設定の反映が必要です。稼働中ディスクを複製しない構成も検証します |
| データ保全 | VM情報の原子的な保存、履歴の破損対策、バックアップと復元、履歴が増えた場合の検索を検証します |
| 認証と隔離 | API・画面配信の認証、環境から管理APIへの到達制限、秘密情報の保護、危険操作の承認を追加します |
| 実行制限 | アクション数に加えて、経過時間・トークン・費用の上限とタイムアウトを検証します |
| 日本語入力 | VNCのASCII制限を解消し、日本語を入力して保存する試験を追加します |
| 品質評価 | 実LLMによる定型作業の成功率・所要時間・使用量を測ります。モデルと環境を固定して比較します |
| 使い勝手 | 定型タスクのテンプレートと複数環境の同時監視を検討します。決定モデルは評価結果を確認してから有効にします |

## 参考にした設計

[Agent S](https://github.com/simular-ai/Agent-S)と[OSWorld](https://github.com/xlang-ai/OSWorld)の評価方法を参考に、実際にできたファイルの内容を検査するテストを追加しました。

[Browser Use](https://github.com/browser-use/browser-use)の実行上限と秘密情報の扱いを参考にしています。回復操作にも上限を適用し、秘密情報の保護は未実装として追跡します。
